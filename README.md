# kneelbooks-
KneelBooks — bended knee and sharpened mind.

Free library. Read The Laws of Money and more.

**Live site:** https://mahlatseeducation-ops.github.io/kneelbooks-/

## Features
- PWA installable on Chrome & Safari (popup on open)
- Offline reading via service worker
- Flipbook + scroll reader
- Progress tracking

## Deploy
This is a static site. All files in root are served via GitHub Pages.

To update:
1. Replace `index.html` and `sw.js`
2. Commit & push — Pages deploys in ~1 minute

To test install popup:
- Open `https://mahlatseeducation-ops.github.io/kneelbooks-/?reset=1`
- Popup shows after 1s

Icons: `icon-192.png`, `icon-512.png` — do not change (black kneeling figure)
